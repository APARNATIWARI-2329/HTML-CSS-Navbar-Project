# 🌐 Responsive Navigation Bar

A responsive navigation bar built using HTML and CSS, designed to practice modern frontend development concepts including Flexbox, navigation layouts, SVG icons, and responsive UI design.

---

## 🚀 Features

* Responsive navigation layout
* Flexbox-based positioning
* SVG dropdown icons
* Logo and profile integration
* Clean and modern user interface
* Organized HTML structure and CSS styling

* CSS3
* Flexbox
* SVG Icons
